BLACKYARD CAFE & RESTRO — NEXORADIGITAL SAMPLE WEBSITE

Open index.html in a browser to preview locally. All generated food image assets are included in images/ and use relative paths.

Important:
- Food photos are AI-generated illustrations, not photos of Blackyard's actual servings or premises.
- Dish names and broad descriptions were cross-checked against Blackyard's website and online menu listings.
- Please confirm current menu, prices, opening hours, contact details and official social links with the business before using this as an official website.
- Google Fonts are remotely loaded; the page still works with system font fallbacks if fonts are unavailable.

GitHub Pages:
1. Extract the ZIP.
2. Create a new GitHub repository (e.g. blackyard-demo).
3. Upload index.html, README.txt, and the entire images folder. Keep the folder structure unchanged.
4. Open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
6. Wait for GitHub Pages to publish. Expected URL format: https://YOUR-USERNAME.github.io/REPOSITORY-NAME/ . This is not a confirmed live URL until GitHub shows the deployment as published.
